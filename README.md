A deterministic program that writes one single-line joke excusing a missed deadline — a breakup joke: the deadline wanted commitment, and the speaker wanted to see other projects. One sentence, one line, under the 200-character cap, so it passes the gate and reads like something a person would actually say when cornered.

## Run it

```sh
python3 main.py
```

It writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validates it against the gate (1–200 characters, single line, valid UTF-8, not only whitespace), then reads the file back to confirm the bytes on disk are exactly the joke it wrote.
